# ☕ WL — With Love

**Coffee, Made With Love.**

WL — With Love is a modern, responsive coffee website designed to create a warm and welcoming digital experience for coffee lovers. The project combines an elegant coffee-inspired design with interactive features and multilingual support.

## ✨ Features

- **Responsive Design** — Optimized for mobile, tablet, and desktop screens.
- **Home Page** — A welcoming hero section with coffee imagery and engaging content.
- **Our Coffee Page** — Browse coffee products and filter them by category.
- **Interactive Filters** — Select multiple coffee categories or display all products.
- **About Page** — Learn more about the brand and its values.
- **Contact Page** — Contact form and location information.
- **Multilingual Support** — Switch between Armenian, English, and Russian.
- **Reusable Components** — Built with reusable React components for maintainability.
- **Modern UI** — Styled with Tailwind CSS and a coffee-inspired color palette.

## 🛠️ Built With

- **React.js** — Building the user interface.
- **JavaScript (ES6+)** — Interactive functionality.
- **Tailwind CSS** — Responsive styling and layout.
- **React Router** — Navigation between pages.
- **i18next / react-i18next** — Multilingual support.

## 🚀 Getting Started

Follow these steps to run the project locally.

### Prerequisites

Make sure you have [Node.js](https://nodejs.org/) and npm installed.

### Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/NarekPoghosyan78/WL-coffee
   ```

2. Navigate to the project directory:

   ```bash
   cd coffee WL
   ```

3. Install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL shown in your terminal.
